- Pesquisa avançada com filtros combinados.
- Filtros por cidade, UF, bairro, congregação e status.
- Filtros por primeira e última visita.
- Filtros por quantidade mínima e máxima de visitas.
- Filtro de decisão: aceitou Jesus / não registrado.

- Histórico de visitas preservado.
- Registro de decisões espirituais.
- Registro de acompanhamentos.
- Dados fictícios criados automaticamente para testes.
- Banco DEV separado: data/database_dev.db.
